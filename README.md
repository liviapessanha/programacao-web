# Projeto Programação Web


#### Este sistema tem como objetivo otimizar o processo de atendimento em clínicas veterinárias, permitindo o gerenciamento eficiente dos animais e consultas. A aplicação oferece funcionalidades tanto para Funcionários quanto para Clientes, garantindo um fluxo de trabalho organizado.

## Funcionalidades

### Para Funcionários:
- **Cadastro, edição e exclusão** de **animais** e **consultas**
- Visualização de **consultas agendadas** e animais de clientes.
- Gerenciamento centralizado de informações da clínica.
- Alteração de **dados pessoais** e **senha**.

### Para Clientes:
- Cadastro de **animais**.
- Visualização das **consultas agendadas** para seus animais.
- Alteração de **dados pessoais** e **senha**.
